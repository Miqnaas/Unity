Sunnyland Adventure - Unity source project

1. Extract this entire folder.
2. Unity Hub > Add project from disk > choose this folder.
3. Open using Unity 2022.3.62f3 LTS.
4. Open Assets/Game/Scenes/Start.unity and press Play.
