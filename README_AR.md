# Sunnyland Adventure — مشروع Unity

لعبة منصات 2D للكمبيوتر مبنية على أصول Sunnyland التي أرفقتها. الحزمة الأصلية كاملة موجودة تحت `Assets/SunnyLand Artwork` مع الاحتفاظ بملفات `.meta` ومعرّفاتها الأصلية. ملفات لعبتنا تحت `Assets/Game`، والمشروع منفصل عن مستودع SWQS-BMY.

## التشغيل

1. فك ضغط المشروع كاملًا.
2. افتح Unity Hub، ثم **Add → Add project from disk**، واختر المجلد الذي يحتوي على `Assets` و`Packages` و`ProjectSettings`.
3. افتحه باستخدام **Unity 2022.3.62f1 LTS**. سيحتاج أول فتح اتصالًا لتنزيل حزم Unity، ومنها Test Framework.
4. انتظر انتهاء الاستيراد وتجميع C#.
5. اختر **Sunnyland → Open Start Scene**، أو افتح `Assets/Game/Scenes/Start.unity` يدويًا، ثم اضغط **Play**.
6. اختَر المرحلة الأولى. المرحلتان التاليتان تُفتحان بعد إنهاء السابقة.

لا تحتاج لإعادة استيراد ملف `.unitypackage`، ولا لتوصيل مراجع يدويًا. الكتالوج والمشاهد وبيانات المراحل موجودة بالفعل.

## اللعبة

- **Meadow Trail:** تعلّم الحركة والقفز، واجمع 3 جواهر.
- **Mossy Crossing:** فجوات وضفادع وفخاخ أكثر، واجمع 4 جواهر.
- **Eagle Heights:** المرحلة النهائية، مع أعداء طائرة و5 جواهر.
- الوصول إلى البيت ينهي المرحلة بعد جمع الجواهر المطلوبة.
- الكرز يمنح نقاطًا. القفز فوق العدو يهزمه، ولمسه من الجانب يسبب ضررًا.
- للاعب 3 قلوب في كل محاولة و3 محاولات في المرحلة. السقوط أو نفاد القلوب يستهلك محاولة.
- اللافتات الخشبية نقاط حفظ داخل المرحلة. العناصر المجموعة تظل مجموعة عند الرجوع إلى نقطة الحفظ.
- النجوم: نجمة لإنهاء المرحلة، ونجمة لعدم فقدان أي محاولة، ونجمة لإنهائها قبل الوقت المحدد.
- تُحفظ المراحل المفتوحة وأفضل النتائج والنجوم والأزمنة وإعداد الصوت محليًا بـ`PlayerPrefs`.
- نقطة الحفظ والمحاولات الحالية لا تُستأنف بعد إغلاق اللعبة؛ عند إعادة الفتح تبدأ المرحلة من بدايتها.

## التحكم

| الوظيفة | الزر |
|---|---|
| التحرك | A / D أو الأسهم يمين / يسار |
| القفز | Space أو W أو السهم لأعلى |
| قفزة قصيرة | اترك زر القفز مبكرًا |
| إيقاف مؤقت / استكمال | Esc |
| العودة لنقطة الحفظ مع استهلاك محاولة | R |
| التنقل بين أزرار القوائم | أعلى / أسفل أو Tab، ثم Enter |

القوائم باللغة الإنجليزية لتجنب مشاكل عرض العربية في الخط الافتراضي. توجد قائمة تعليمات، وتحكم في الصوت، وإعادة المرحلة، والعودة إلى القائمة الرئيسية.

## العلاقة بالسكاشن

الملفان المقدمان يشرحان تثبيت Unity وإنشاء مشروع واستيراد الأصول، ثم Tilemap وRigidbody2D وحركة اللاعب وتغيير اتجاهه وColliders. لا يتضمنان تكليفًا مكتوبًا يحدد ثلاث مراحل أو أعداء أو شروط تسليم. هذه الأجزاء إضافات لإكمال دورة اللعبة، وليست متطلبات منسوبة للمعيدة.

| موضوع السكشن | موضعه في المشروع |
|---|---|
| استيراد الأصول | `Assets/SunnyLand Artwork` و`Resources/SunnylandCatalog.asset` |
| Tilemap وGrid | `WorldBuilder.cs` يبني أرض المراحل من بياناتها |
| Rigidbody2D | لاعب Dynamic، وأعداء Kinematic، وأرض Static |
| GetComponent وUpdate / FixedUpdate | `PlayerController.cs` |
| حركة اللاعب | قراءة الأزرار في Update وتطبيق السرعة في FixedUpdate |
| تغيير الاتجاه | `SpriteRenderer.flipX` |
| تصادم اللاعب والخلفية | BoxCollider2D وTilemapCollider2D وCompositeCollider2D |

## تنظيم الملفات وتعديل المراحل

- `GameRoot.cs`: حالة اللعبة، المحاولات، النتائج، الحفظ والصوت.
- `PlayerController.cs`: الحركة والقفز والضرر.
- `EnemyController.cs`: دوريات الأعداء والقفز فوقهم.
- `WorldTrigger.cs`: الكرز والجواهر والفخاخ ونقاط الحفظ والبيت.
- `Flipbook.cs`: أنيميشن باستخدام إطارات Sunnyland الأصلية.
- `CameraFollow.cs`: تتبع اللاعب وحدود الكاميرا.
- `GameHUD.cs`: واجهة اللعب والقوائم، باستخدام IMGUI دون خطوط أو أصول خارجية.
- `Resources/Level1.json` إلى `Level3.json`: بيانات الأرض والعناصر والأعداء.
- `Scenes/Start.unity`: نقطة بدء اللعبة. المشاهد الثلاثة الأخرى تشغّل المرحلة المحددة مباشرة للتطوير، حتى إذا لم تُفتح في الحفظ.

المراحل تُنشأ عند الضغط على Play؛ لذلك المشاهد في وضع التعديل تحتوي على جذر اللعبة فقط، وليست خرائط Tilemap مرسومة مسبقًا. أثناء Play تظهر الأرض واللاعب والعناصر في Hierarchy. عدّل ملفات JSON لتغيير التصميم، ثم أعد التشغيل. في كل GroundSpan، `x` بداية المنصة، و`width` عرضها، و`y` صف البلاط العلوي، و`depth` عمقها. حجم خلية الأرض وحدة واحدة.

التقدم الذي تحفظه تجربة مرحلة مباشرة من مشاهد التطوير قد يفتح مراحل لاحقة. لإعادة البداية استخدم **Sunnyland → Reset Saved Progress (local only)**؛ يؤثر ذلك على بيانات لعبتنا فقط.

## الاختبارات والبناء

**المحرر غير متاح في بيئة إنشاء هذا التسليم.** لم يتم تشغيل Play Mode أو تجميع المشروع بمكتبات Unity أو إنتاج EXE هنا. نجاح فحص تركيب C# وفحص الملفات لا يثبت صحة اللعب أو البناء داخل المحرر.

الفحوص التي يمكنك تشغيلها:

1. **Sunnyland → Validate Project** لفحص الكتالوج وبيانات المراحل.
2. **Window → General → Test Runner**، ثم شغّل مجموعتي **EditMode** و**PlayMode**. الاختبارات مرفقة، ولم تُنفذ في هذه البيئة.
3. أكمل قائمة الاختبار اليدوي في `TESTING.md`، خصوصًا التصادم والقفز والصوت والواجهة على جهازك.
4. لبناء Windows، ثبّت **Windows Build Support** من Unity Hub، ثم اختر **Sunnyland → Build Windows x64**. الناتج في `Builds/Windows`.
5. خيار **Build Linux x64** متاح أيضًا إذا كانت وحدة Linux مثبتة.

أوامر اختيارية بعد توفر محرر Unity مرخّص:

```text
Unity -batchmode -nographics -projectPath <project> -runTests -testPlatform EditMode -testResults <results.xml> -logFile <editor.log>
Unity -batchmode -nographics -projectPath <project> -executeMethod Sunnyland.Editor.ProjectTools.BuildWindows -quit -logFile <build.log>
```

لا تستخدم `-quit` مع أمر Test Runner. اختبار PlayMode يُفضّل تشغيله من المحرر أولًا.

الفحص المستقل، الذي لا يحتاج Unity:

```text
python Tests/validate_project.py
```

يحافظ المشروع على كامل الحزمة المرفقة، لكنه يستخدم مجموعة مناسبة منها داخل المراحل، وليس كل ملف رسومي وصوتي في مشهد واحد. راجع شروط الترخيص الأصلية قبل نشر الأصول أو توزيع اللعبة تجاريًا.
